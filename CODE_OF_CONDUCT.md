# Code of Conduct

## Our standard

This project follows one simple principle, borrowed from the man it's built around: be direct, be respectful, and don't waste people's time.

In practice:

- Critique ideas, not people
- Be specific — vague complaints help no one
- Assume good intent until proven otherwise
- Keep discussions on topic

## Unacceptable behaviour

- Harassment, personal attacks, or discriminatory language of any kind
- Spam or off-topic promotion
- Deliberate intimidation or trolling

## Enforcement

Violations may result in comments being removed or contributors being blocked from the repository. This is a small project — bad actors will be removed without extended debate.

## Reporting

To report an issue, open a GitHub issue marked **[conduct]** or contact the repository owner directly via GitHub.
